# Release Instructions

Follow these instructions before creating a new release.

1. Change the version number in docs/version, bmsg.desktop, and in gui.py.
2. Add all changes to the changelog.
3. When creating the release on the GitHub repo, paste the changelog info into the release description.
4. Going by major.minor.hotfix standards, label the release as "Release" if the major or minor version is changed, or "Hotfix" if hotfix was changed.
